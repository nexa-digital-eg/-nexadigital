# Nexa Digital — Website

> **Smart Solutions. Digital Future.** — حلول ذكية. مستقبل رقمي.

The official website for **Nexa Digital**, a full-service digital agency offering
Websites, Systems, Automation, AI Solutions, and CV & LinkedIn services.

Built as a fast, modern, fully responsive **bilingual (Arabic / English)** site
with full **RTL / LTR** support.

## ✨ Features

- 🌍 **Bilingual** — Arabic (RTL) & English (LTR) with one-click toggle, preference saved.
- 🎨 **Premium dark UI** — matches the Nexa Digital brand (electric blue + silver).
- ⚡ **Fast & responsive** — looks great on phones, tablets, and desktops.
- 🎬 **Smooth animations** — scroll reveals, counters, and micro-interactions (Framer Motion).
- 📞 **Direct contact** — WhatsApp, call, and email links + floating WhatsApp button.
- 🔍 **SEO-ready** — metadata, Open Graph, sitemap, and robots.

## 🧩 Sections

Navbar · Hero · Services (5) · Stats · About · Process · Portfolio · Testimonials · FAQ · Contact · Footer

## 🛠️ Tech Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [lucide-react](https://lucide.dev/) icons

## 🚀 Getting Started

```bash
# install dependencies
npm install

# run the dev server
npm run dev
# open http://localhost:3000

# production build
npm run build
npm run start
```

## ✏️ Editing Content

- **Contact details** (phone, WhatsApp, email): `src/lib/site.ts`
- **All text** (Arabic & English): `src/lib/i18n/translations.ts`
- **Brand colors & theme**: `tailwind.config.ts`
- **Sections**: `src/components/*`
